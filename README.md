# PixelCompass

PixelCompass is a real-time, multi-threaded metadata aggregator that processes large datasets through auto-scaling, enhancing system performance.

PixelCompass is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/PixelCompass.git`
2. `cd PixelCompass`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure PixelCompass, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
